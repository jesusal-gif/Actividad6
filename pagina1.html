HTML: el esqueleto de la web

HTML (HyperText Markup Language) es el lenguaje con el que se describe el contenido de una página. No es un lenguaje de programación: marca qué es cada cosa, ya sea un título, un párrafo, una imagen o un enlace.

Cada elemento se escribe con <etiquetas> de apertura y cierre. Los títulos van del <h1> al <h6>, los párrafos usan <p> y las imágenes <img>, siempre con un texto alternativo para accesibilidad.

Lo que convierte a la web en una "red" son los hipervínculos. Con <a href="pagina2.html"> podemos saltar de una página a otra, que es justo lo que hace el menú de este sitio.

<nav>
  <a href="index.html">Inicio</a>
  <a href="pagina1.html">Página 1</a>
</nav>
Dato útil: el navegador ignora los saltos de línea y espacios repetidos del código HTML. Para separar contenido se usan etiquetas, no enter.

Tres etiquetas que usarás siempre

<a> · Enlaces

Conecta páginas entre sí o con otros sitios mediante el atributo href.

<p> · Párrafos

Agrupa el texto corrido. El navegador agrega un espacio entre cada párrafo.
