JavaScript: la web cobra vida

JavaScript es el lenguaje de programación del navegador. Permite reaccionar a lo que hace la persona: un clic, una tecla, el envío de un formulario o el movimiento del cursor.

Trabaja sobre el DOM, la representación en memoria del HTML. Con él se pueden buscar elementos, cambiar su texto, agregar clases de CSS o crear contenido nuevo sin recargar la página.

Muchos componentes de Bootstrap, como los modales y los acordeones, funcionan gracias a JavaScript. Pulsa el botón para ver un modal en acción.

Conceptos clave

Una función agrupa instrucciones reutilizables. Las funciones flecha son una forma corta de escribirlas.

const saludar = (nombre) => `Hola, ${nombre}`;
console.log(saludar("FIME"));

Con addEventListener ejecutamos código cuando ocurre un evento sobre un elemento del DOM.

document.querySelector("#boton")
  .addEventListener("click", () => {
    alert("¡Hiciste clic!");
  });

Orden recomendado para aprender

  1. HTML para estructurar el contenido
  2. CSS para darle estilo y adaptarlo a pantallas
  3. JavaScript para hacerlo interactivo
  4. Git y GitHub para guardar y compartir cada cambio
