CSS: dale estilo a tu página

CSS (Cascading Style Sheets) controla cómo se ve el HTML: colores, tipografías, márgenes, tamaños y posición. Separar el contenido del diseño permite cambiar toda la apariencia de un sitio editando un solo archivo.

Una regla de CSS tiene un selector que indica a qué elementos se aplica y un bloque de propiedades entre llaves. Puedes seleccionar por etiqueta, por clase con un punto o por identificador con un numeral.

Para acomodar el contenido hoy se usan Flexbox y Grid. Bootstrap se apoya en ellos para ofrecer su sistema de columnas, que adapta la página a celulares, tablets y computadoras.
